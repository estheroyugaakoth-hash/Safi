# SAFI – Home Services Booking System

## About the Project

SAFI is a web-based home services booking system designed to make it easier for customers to find and book home services. The system allows customers to explore available services, submit booking requests, and send enquiries.

It also includes an administrative dashboard where administrators can manage customer bookings and messages.

## Features

### Customer Features
- Browse available home services.
- View information about the services offered.
- Submit service booking requests.
- Send enquiries through the contact form.

### Administrator Features
- Secure administrator login.
- View and manage customer bookings.
- Update booking statuses.
- View customer messages.
- Manage the system through an admin dashboard.

## Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Interactive functionality.
- **PHP** – Server-side processing.
- **MySQL** – Database management.
- **XAMPP** – Local development environment.

## Database

The project uses a MySQL database named `safi_db` to store booking information, customer messages, and administrator details.

## Installation and Setup

1. Install XAMPP on your computer.
2. Copy the SAFI project folder into the `htdocs` directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Open phpMyAdmin and create the database `safi_db`.
5. Import the project's database tables if an SQL file is provided.
6. Configure the database connection in the project.
7. Open your browser and visit:

   `http://localhost/safi/`

## Project Purpose

This project was developed to demonstrate practical skills in frontend development, backend programming, database integration, form handling, and administrative system management.
